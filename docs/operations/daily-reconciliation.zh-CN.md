# 平台指标与券商账本逐日证据表

[English](daily-reconciliation.md) · [比赛核对](competition-review.zh-CN.md)

先保留缺失、核对逐日证据，再讨论参赛资格或策略活动。命令从已封存且可复算的Flex快照重建账本，校验申报回执；可选接入现有[审核后每日证据包](competition-review.zh-CN.md)。它不会登录、下载账户数据、推断主办方公式或下单。

```bash
python -m competition_tools.competition_review.daily_reconciliation \
  --declaration-root /external/captured-declaration \
  --snapshot-root /external/sealed-reconciled-flex \
  --output /external/new-daily-table
```

未传入 `--statement-bundle /external/reviewed/bundle.json` 时，平台列保持为空。输出包含封存的reconciliation.json及双语报告。保留全部券商净值/执行日期；提供平台包时，保留其全部已结束日历标签，包括资料不全或缺失的日期。执行记录按来源交易编号去重；零笔已报告记录不证明实际没有交易。已有ledger.json必须与重算结果完全一致。输出前检查快照回执、时间、哈希和账户。

提供的证据包必须绑定同一申报哈希、账户别名和基础货币，引用原始文件哈希，使用比例值，并通过现有日历、覆盖程度和可得时间校验。这是对保留证据的审核后归一化，不是新建一个任意CSV解析器。没有的值保持为空，不能填示例比例。缺失、篡改或混用账户不能变成已确认的每日事实。

券商股票总值/NAV只是代理值，不是官方持仓率。表中的“代理值减所提供值”只描述数值差；零不证明一致，非零不证明错误。日期标签相同也不证明时区/交易日映射一致。来源和organizer_confirmed标签仍是归属声明。本表不认证正式资格、不改变现有参赛评分逻辑、不授权交易。

## 到哪里找平台数据

按负责人之前提供的页面布局，进入 **策略管理 → 策略详情 → 持仓率与换手率**，查看有无可见的导出/下载按钮或图表菜单。这不是在断言平台一定提供导出。如果有表格，保留完整日期范围、单位与完整性说明。图表或截图可以证明当时显示的值，但不等于完整原始每日明细、日历和公式。

没有导出入口时，可向主办方索取与账户绑定的每日表和计算定义。回复及原始附件保留在Git之外。下面是可直接使用的文字草稿，工具不会发送：

> 您好，请提供我们策略的每日持仓率、每日换手率、累计空仓日明细及计算公式，并说明分母交易日历、时区、日内持仓、外汇和衍生品处理，以及比例采用小数还是百分数。另请告知：当申报介绍与当前实际占位持仓存在差异时，应如何补充说明？

索取这份明细不需要发送Flex Token或券商登录密码。只有浏览器连接可用时才能使用已连接页面；连接不可用不授权探测私有接口或寻找无关凭据。

## 前瞻观察与跨假期核查

[候选观察](candidate-observations.zh-CN.md)仍使用原冻结窗口；准备对账表不等于完成未来观察或安装自动任务。缺失或迟到的记录保持缺失。[ETF逐日路径](etf-rehearsal.zh-CN.md)中的日本过期价格，应比较原始行情最后交易日与XTKS日历最后已完成交易日。即便确因休市而没有新价格，也可能仍违反冻结的72小时上限。单独记录这个区别，不在看过收益后修改上限或覆盖原阻断结果。替代估值政策需要另行冻结研究版本，不能追认历史结果。
