# 跨资产配置与加密货币仓位

[English](multiasset-crypto.md) · [文档目录](../README.zh-CN.md)

这项离线研究沿用静态配置实验，检验不同资产敞口和少量加密仓位能否在计入模型费用后改善现金支持的基线。历史比较不授予比赛账户交易权限，也不构成独立样本外成绩。

## 设计与范围

资产池按作用选择，覆盖股票、名义国债、通胀挂钩债券、黄金和广泛商品，并明确保留现金。美国低波股票代理不能代表全球股票。同类产品可能重复承担风险。通胀挂钩债券仍受实际利率影响，商品基金收益还受产品结构和期货展期影响。

桥水的[全天候说明](https://www.bridgewater.com/research-and-insights/the-all-weather-story)提供了按增长与通胀意外变化分散风险的思路。等金额和波动率倒数配置只是简单对照，不能代表桥水专有配置或基于完整协方差的风险平价。波动率倒数忽略相关性。新数据采集前固定估计区间、权重限制和舍入方式，分别记录拟合权重与随后收益。

比较既有股票加现金基线、分散资产等金额配置和固定的波动率倒数配置。在分散基线上单独加入加密仓位，以现金支付。这样会增加投资敞口，各组总风险并不相同。为较大的加密仓位设置相同权重的股票替换现金对照。较小的加密仓位没有资金匹配的股票对照，仅作探索。资产标识、日期、权重和私有实测结果保存在外部协议与报告中，不根据已见收益搜索参数。

## 加密货币的两条研究路径

首轮合并账本可以使用比特币和以太币上市产品，与其他产品采用相同的美国交易所交易日。上市产品有费用、上市日期和闭市间隔，不能用现货价格补出上市前的产品历史。发行方分别说明了 [IBIT 的比特币敞口](https://www.ishares.com/us/products/333011/ishares-bitcoin-trust-etf)和 [ETHA 的以太币敞口](https://www.ishares.com/us/products/337614/ishares-ethereum-trust-etf)。纳入研究不代表当前账户具备购买权限。

已保留的 BTCUSDT／ETHUSDT 现货数据单列。USDT 与 USD 币种不同。合并现货与交易所日线前，需要明确周末收益、资金与托管成本、交易所风险，以及估值和决策时钟。不能向前填充美股价格后，假设各类资产都能在同一时点成交。加密货币能否分散风险需要测量，不能保证抵御通胀。

[IBKR 权限说明](https://www.interactivebrokers.com/campus/trading-lessons/adding-cryptocurrency-trading-permissions/)列出了资格和权限要求。券商提供产品、项目已有加密研究，都不能证明当前比赛 Paper 账户可交易，也不能证明比赛如何认定或执行 schema 已支持。另见[比赛规则](../competition/rules.md)。本实验不请求券商接口，不提交订单，不修改账户设置。

## 现有回放与复现

使用独立安装的 equity-lab CLI。根项目通过文件交换数据，不导入叶子研究包。

```sh
python -m equity_lab.backtest.static_allocation \
  --input '<complete-common-session-panel.json>' \
  --protocol '<frozen-static-allocation-protocol.json>' \
  --output '<new-study.json>'
```

输入是由 `{date, open, close}` 行组成的列表，各估值点包含完整的标的与正数价格映射。调用方核对共同交易日、上市覆盖、来源哈希和每日一致的复权因子。现有 `equity.static_allocation_protocol.v1` 要求 USD、现金收益为零，`fees_bps` 为 `[0, 10, 25]`，`policies` 为 `[hold, monthly, drift]`，策略名使用 JSON 字符串。日期、`threshold` 和命名 `targets` 显式提供。各目标权重之和不超过一，剩余为现金。CLI 尚未实现动态波动率倒数权重或现金计息，固定权重只能由事先冻结的历史区间估计。

非加密资产使用较长的共同历史，含加密产品的面板单独使用上市后较短区间。两者分别保留完整基线与实验矩阵，只在相同面板和时期内比较。保存所有结果和每日账本，报告含初始资金的回撤、年化波动、费用、实际敞口与逐年收益，标明不完整年份。末次净值计入退出费用，末次权重描述退出前持仓。

复权价格单位是事后分红调整代理，不能当作券商股数或实际分红现金流。现金按美元零收益计算，不包含账户汇率、税、融资或整手限制。费用档位属于敏感性分析，未验收为券商实际收费表。回撤使用开盘与收盘采样，未覆盖日内极值。单一行情来源尚未通过独立价格或公司行动验收。

缺失交易日或产品历史会阻止对应面板运行。保留失败采集凭据，不悄悄缩短样本。公开采集不使用凭据，并设置资源上限。协议、脚本、输入哈希、采集凭据、验证与解释均放在项目外部数据目录，不提交 Git。保留已有未来观察承诺和共享 latest 指针。新增前瞻研究需要另外冻结协议。

## 验收

核对已安装回放实现的源码哈希和保留的 wheel，独立重算现金、估值及开仓和退出费用，检查未来数据不会影响拟合权重。运行相关叶子测试和仓库检查。成功完成实验只能证明在这些假设下可复现。是否采用仍待独立输入、现金收益、账户币种、权限与可执行策略审查。
