# MoE architecture story implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Publish an independent approachable animated MoE/LSTM topic and contextual research links.
**Architecture:** Pure strict-TS toy/state model plus DOM animation controller, bilingual Astro/SVG topic, small reusable related-topic link. Existing research remains data-identical.
**Tech Stack:** Existing Astro, TypeScript, inline SVG and CSS; no dependency changes.
**Spec:** `docs/superpowers/specs/2026-11-07-moe-story-design.md`

## Global Constraints
Independent EN/zh-CN topic, ten frames and three modes/scenarios. All numbers illustrative; actual last-row router/full expert windows/shared scalar head semantics. Respect reduced motion, manual/noJS fallback,390px/mobile/themes. No models trained or running research changed.

## Review Focus
- Sparse routing must actually show skipping an expert, including a scenario where expert C is selected.
- Equal mode must not imply a learned router; hidden representations must not be presented as independent probabilities.
- Autoplay must stop when hidden/offscreen/reduced-motion changes and must not silently restart after a manual pause.
- Observer-unavailable and no-JS browsers retain coherent useful content.
- Related CNN links must not imply CNN uses MoE or change existing results.
