# LSTM/MoE integration into Global Market Research

Status: approved by the user on 2026-11-06; native implementation authorized. Baselines inspected: global-market-research `b888a3a`, moe-lstm `14742fa`. The user requested integration and a migration notice on the old repository and Pages site.

## Purpose and approach

Make LSTM/MoE an optional offline equity research model within `research/equity-lab`, sharing data validation, evaluation and reporting with existing research. Ask whether input-dependent routing improves prediction or net simulated performance over equally resourced alternatives. Negative results remain results.

Three approaches were considered: rebuild a research platform in moe-lstm (duplicates existing facilities); import moe-lstm as a runtime dependency (retains incompatible dependencies and accounting assumptions); integrate the model ideas into equity-lab with explicit provenance and parity tests (recommended, consistent with the user's integration direction). This is a proposed design, not an approved implementation specification.

The old repository retains Git history, historical results and attribution. Its English/Chinese README and Pages explain the move and link to the new research documentation. The new global site gets a stable LSTM/MoE research route before redirects ship. Keep a manual link visible and use a short, optional automatic redirect only on the old home page, with a canonical destination. Existing historical documentation/results URLs remain readable; no repository deletion or archive setting is required.

Exact internal filenames are builder discretion. Root orchestration calls installed leaf CLIs and reads versioned artifacts. Use a separate optional `neural` extra with PyTorch, selected for explicit gather/dispatch/scatter and gradient tests. Pin compatible versions during implementation and record the lock/environment. Do not add TensorFlow to root dependencies. Reimplement the small mathematical architecture, document moe-lstm ancestry and verify dense forward-pass parity with controlled weights/fixtures. No claim of identical training across frameworks. Inspect the old repository's missing license and preserve author/source attribution; do not declare copied material MIT by assumption. Any copied source requires confirmed licensing/owner authorization before distribution.

Reuse existing leaf validators, portfolio cash rebalancing, measurement and immutable artifact conventions where their semantics match. Existing `predictive.data.prepare_daily` expects minute-derived fields absent from this daily snapshot, so it is not a drop-in input adapter. Existing `holding_account.replay_holdings` requires nonempty selected names and only accepts certain costs: do not silently force it to handle all-flat signals or arbitrary fees. Add a narrowly scoped sequence-study replay using the existing cash rebalance primitive, or extend the account behind a new opt-in contract with regression tests; preserve all existing callers. Do not use demo forward filling or relabel old CNN/ranking results as matched comparisons.

## Data contract and evidence stage

Candidate input: owner dataset `us-fixed-daily/20261021-v2`, external to source. Its manifest declares 10 stocks plus SPY, 953 XNYS sessions, 2023-01-03 through 2026-10-20, IBKR TRADES, USD, split-adjusted prices, fixed-current universe, `accepted_research=false`. Read-only verification on 2026-11-06 matched sizes and SHA-256 for all 66 manifest payload entries. This verifies retained bytes only; it does not authenticate the vendor or establish historical availability. Private absolute locations and exact hashes belong in external run records, not public docs.

The normalized per-symbol CSV fields are `date,open,high,low,close,volume`. Consume an explicitly selected external manifest and expected digest; check receipt/payload bindings, safe relative paths, symbol coverage, unique sorted exchange sessions, finite positive OHLC, coherent price bounds, and finite nonnegative volume. Reject missing required sessions; never forward fill. Record exclusions and fail if held positions cannot be valued. Features never cross symbol boundaries. Use an exchange schedule including holidays, half-days and DST.

Keep the source read-only. Store all environments, models, receipts and outputs in a task-specific directory beneath `DATA_ROOT/global-market-research/research/lstm-moe/`; do not update shared aliases or modify reservations/acceptance state. Record source revisions, manifest/receipt/payload hashes and recheck input hashes at run completion. A changed input invalidates the run. No broker access or new acquisition is needed.

These are exploratory retrospective results: current-stock selection and survivorship bias, previously exposed history, retrospective adjustment availability, unverified action coverage, and no dividends. They cannot qualify as prospective alpha or total-return evidence. Do not infer independent observations by multiplying stocks by dates. A future untouched holdout needs a separately frozen protocol and newly available data; no existing dates receive that label.

Use split-adjusted prices as synthetic research price units, with no extra split cash/share adjustments and no dividend credit. Mark performance as a split-adjusted price-return simulation, not a cash execution ledger or total return. A raw-price/action-aware ledger is a later data-dependent extension; double counting is prohibited.

## Sample and execution timing

Primary protocol: after session t closes, features through t generate a signal; entry is the next session's open, exit/rebalance is the following session's open. One-session target is `open[t+2]/open[t+1]-1`, with threshold 0.002 for binary classification. Class 1 means above threshold, class 0 means not above; positions are long or cash. Signal probability cutoff is 0.5, frozen before the run. Never interpret class 0 as a short. Do not tune the cutoff on test results.

Persist symbol, feature start/end, feature availability, signal time, fit/validation cutoffs, model-ready time, entry/exit sessions and timestamps, prices, target, probability and position. Availability is modeled as exchange close plus 15 minutes; record that this is an assumption, not provider delivery evidence. A model must be ready strictly before entry. For historical fits use a declared 12-hour readiness allowance after the last required label becomes available; entry is permitted only after that allowance. This is a hypothetical readiness budget; live readiness is not established. Boundary selection uses timestamps and skips otherwise ineligible trades.

Labels are available only at exit. Training/validation labels must finish strictly before the next selection/readiness cutoff. Purge any interval violating this condition; default additional embargo is one exchange session. A purge is based on label intervals, not all overlapping feature history. Freeze fold definitions before fitting.

Use rolling 400-session fit + 80-session validation + 63-session test blocks; advance by 63 test sessions, retaining the final shorter block when it has at least 20 eligible sessions. Boundaries count exchange sessions, then apply label/readiness filters. Fit preprocessing and feature selection on fit rows only; validation selects early stopping and declared candidates. Every fold starts in cash and liquidates at its final eligible exit; report independent fold accounts and do not concatenate them as a continuously traded NAV. Also report the exact effective sample counts and excluded edge dates.

## Features and model comparisons

First reproduce the original 5-row, 15-feature dense architecture on controlled fixtures, including corrected long/flat semantics and initial-equity drawdown. This is a compatibility diagnostic with the original timing, not a candidate comparable to the next-open protocol. Do not overwrite its historical results.

For matched new experiments, freeze a relative feature set: close returns, close/MA5 and close/MA20 deviations, open/previous-close gap, high-low/close, close-open/open, RSI/100, MACD/close, rolling 20-session return volatility, and volume/prior-20-session mean-volume. Reject unavailable denominators and warmup rows. Primary lookback is 20; 5 and 60 are declared secondary sensitivity studies. Compare price-level features separately. KMeans/SOM and correlation filtering are a later feature ablation after routing is measured; all selectors fit only fit rows and save ordered selected names.

Initial matched suite: cash, same-period holding, a frozen 20-session momentum rule, logistic regression, LSTM-64, parameter-matched single LSTM, three jointly trained equal-weight LSTMs, three independently trained probability-averaged LSTMs, dense learned-gate LSTM, and truly dispatched top-2 LSTM. Matching uses actual feature count/lookback/head and records parameter counts; solve for the nearest single-LSTM width rather than assuming 116 always matches. All learnable candidates share data, labels, preprocessing and split definitions. The primary panel uses one pooled model per candidate/fold/seed, with windows confined to each stock and shared fit-only scaling estimated over eligible stock fit rows. SPY is excluded from pooled fitting and is used only for a separate end-to-end smoke; a full SPY suite is a secondary study with its own budget. No symbol embeddings are used initially. Equal and independent expert ensembles follow this same pooled population.

Dense parity retains complete-sequence flattening and the last-bar router. The primary sparse comparison uses the same router, experts and head; only dispatch changes. Gather selected windows per expert, skip empty expert batches, scatter weighted representations back. Instrument actual expert calls and processed sample counts in training and inference. Top-2 renormalizes selected probabilities. An optional top-1 experiment retains the selected softmax probability without renormalizing it to one; prove nonzero task gradients under a controlled nondegenerate fixture. Hard index selection is nondifferentiable; document this surrogate. Test selected expert gradients and zero contribution from unselected samples.

Balance loss is separate from task loss and reported separately. Save router probabilities, chosen indices, load, entropy, collapse diagnostics, expert representations/probes, and fixed-average/drop-expert ablations. Shared-sequence router and shared-encoder/FFN experts are distinct secondary model IDs, never substituted in the primary routing comparison.

Only after the LSTM suite is working add a small dense Transformer and matched FFN-MoE Transformer: 2 layers, width 64, 4 heads, 4 FFN experts with top-2, 60-session lookback. A token is one day of numerical features; output uses the final historical representation. Bidirectional attention inside the fully historical window is allowed; no per-position future targets are exposed. Compare at matched total and active parameter budgets where feasible and report mismatches. No pretrained checkpoint is needed. Any later pretrained candidate needs a training-cutoff/overlap audit.

## Accounting, statistics and resource budget

Primary exploratory account: no shorts, leverage or interest; equal initial per-symbol sleeves for the 10-stock panel, each investing its sleeve fully on long signals and otherwise cash. No cross-sectional top-k ranking is implied. Evaluate SPY separately; panel comparisons use the same pool and capital. Costs are 0, 5, 20 and 40 bps per side on actual traded notional, including initial entry and final exit. Cash/share arithmetic must reconcile at every mark. Report gross, net, turnover, exposure, trade count, return, drawdown from initial equity 1 and Sharpe with its daily calendar/variance assumptions. Zero-trade and constant-score cases are visible, with undefined metrics null plus reasons. No measured spread, market impact or borrow claim is made.

Five fixed seeds (11, 23, 37, 53, 71), maximum 50 epochs, patience 5, batch 32; record determinism settings. Start with synthetic tests and one-seed/one-fold SPY smoke (maximum 10 minutes). Before real fitting, precompute candidate/fold/seed attempts and persist the schedule. Full LSTM stage has a 6-hour wall-clock and 600-fit cap (an independent three-model ensemble counts as three fits); the preflight refuses to start if the frozen schedule exceeds that cap, rather than promising an inherently incomplete suite. For example, seven folds and five seeds require at most 315 fits for the seven learned candidate families, counting the independent ensemble three times. Once running, stop with partial status instead of silently shrinking the suite or selecting survivors. Transformer and secondary ablations have separate 6-hour/240-fit caps and remain pending until the primary stage is complete. No automatic hyperparameter search. Record CPU/GPU, peak memory, synchronized fit/inference latency, warmup/repetitions, total and active parameters and processed expert sample counts. Sparse routing is not called faster without measurements.

Retain paired predictions for identical dates. Report per-fold and per-seed results and paired differences against the parameter-matched LSTM/equal-weight MoE. Use moving date-block bootstrap (20-session blocks, 2,000 draws, fixed seed 20261106), resampling all stocks together and never crossing independent fold boundaries. Keep seed and temporal variation separate. Intervals are exploratory diagnostics, not proof of independent discovery; no automatic significance-based promotion. Classification AUC, log loss, Brier score and reliability bins explain predictions; net performance and risk remain separate outcomes.

Every immutable run bundle includes schema version, status/partial reason, frozen config/schedule, revisions, environment/lock, data bindings and caveats, feature order, scaler/selector state, serializable model checkpoints, seeds, sample/fold timing tables, probabilities, routing diagnostics, fills/account marks, metrics, paired uncertainty and checksums. Round-trip loading must reproduce fixture predictions. Existing CSV reports and old CLI remain compatible until the old repository's migration notice points readers to the replacement command.

Add a global-site research page with evidence stage, data limits, zero-trade warnings, model/fold/seed choices and downloadable permitted summaries. Use lazy, locally bundled ECharts line modules for zoom/hover/series toggles; HTML tables for confusion matrices and accessible fallback summaries. English is default with Chinese catalogs. Charts use a versioned projection contract rather than arbitrary private paths.

Publication rights for this dataset remain unverified. Default public chart fixtures are synthetic, explicitly labeled; raw OHLCV, individual benchmark paths and real derived time series are excluded. Real aggregate publication requires the existing owner review/allowlist process and documented rights. Do not replace old public snapshots. Measure compressed JS+data versus current PNG payload and report the result; do not promise ECharts is smaller or reduce data fidelity without disclosure.
