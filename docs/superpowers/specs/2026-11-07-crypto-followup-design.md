This task audits existing forward receipts, explains cash decisions, resolves provider semantics where public sources permit, runs one bounded retrospective four-hour sequence comparison, and publishes a source-backed research journal. No running observer, frozen producer, existing plan or saved model is changed.

## Evidence and experiments
- Snapshot the append-only observation prefix; seal the audit. Verify commitments precede entry, outcome deadlines, duplicates, receipt bindings and score reconstruction. Report counts, revisions, lateness and aggregate forecast error; a few hours validate plumbing, never significance. Do not wait48h or extend the process.
- Inspect saved Ridge scores without refits. Report prediction/target quantiles and fractions above fixed0/10/20bp hurdles by fold/model/grain. These are explanatory retrospective sensitivities, not selected new strategies.
- Inspect only public Cryptoracle documentation, retain bounded source downloads externally. Distinguish documented definitions/frequency/timezone from snapshot metadata and first publication/revision evidence. No paid/private API calls. Unknown remains unknown.
- Freeze a four-hour-only retrospective price-feature comparison: Ridge, single LSTM8, parameter-matched single LSTM, three equal experts8, learned dense three experts8. Same twelve-bar windows, seven price features, common factor-intersection eligible dates, labels, delayed entry, fit-only scaling and three original chronological test folds. Three fixed seeds11/29/47 for neural models; Ridge once per fold;39 expected fits. Five epochs, Adam lr0.001, batch256, CPU one thread, no hyperparameter search. These are historical tests already examined, explicitly exploratory, not fresh holdouts or superiority evidence.

Persist checkpoints, scale, probabilities/predictions, decision choices, accounts, gate usage/entropy and elapsed time. Safe tensor weights only, no pickle loading. No existing production runtimes modified.

Strict TS/lazy charts remain; static facts work without JS. Closed aggregate export excludes raw rows, individual forecasts, host paths and configuration.
