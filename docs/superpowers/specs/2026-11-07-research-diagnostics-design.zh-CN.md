# 研究诊断与维护

用户已授权推进五项后续工作，并要求连续执行、减少确认。基于 main 0a51b47 创建任务工作区，保留其他 Paper 工作区和封存实验。不连接券商、不购买或采集数据、不公开真实研究序列，也不改变研究验收状态。

复用原预测、模型及数据证据检查，新增独立诊断运行包和离线 HTML 浏览器，不建设新托管服务。诊断归 equity-lab，根治理工具只消费文件契约，不导入叶子包对象。不重新训练神经网络。

诊断全部模型的类别比例、概率分布、十分箱校准、Brier/log loss/AUC 及超过 0.5 的比例；使用保存的特征、缩放器和模型重建验证段预测，先要求测试概率与原值在 1e-6 内一致。等权模型和单专家不把未参与决策的路由器解释为有效门控。

对 matched/equal/dense/sparse 增加每日再平衡 25%/50% 仓位、验证段确定的暴露和波动率仓位，以及根据当时已知的 20 日组合收盘收益计算的 10% 年化波动目标仓位。权重限制 [0,1]，不杠杆，现金无利息。所有账户使用相同股票、日期及每边 0/5/20/40 基点费用，包含首次入场和最终退出。验证段设定的目标不保证测试段实际暴露或波动相同，须报告偏差。扩展分数仓位回放并保持原二元接口和计算结果。

阈值候选固定为 [0.35,0.425,0.5,0.575,0.65]，只按验证段 5 基点扣费后的日均收益选择；并列优先接近 0.5，再选较高阈值。保留所有候选、选择时点和尝试数量。原早停也使用验证段，因此这是已接触历史上的追加探索，不是盲测。此阶段先诊断校准，不拟合新校准器。真实回放上限 30 分钟，中断或失败如实记录状态。新包独占创建，绑定父包摘要、输入和源码，结束时重验，不覆盖原结果。

浏览器是单个本地 HTML，无网络请求和服务器依赖，支持模型、切分、种子、费用筛选，权益/暴露图、概率/校准表、门控负载与来源信息。默认英文，中文使用独立词条；可用时保存语言选择，无 JS 时仍可读表格及状态。模板随安装包分发，真实结果保留私有。Pages 只链接使用文档。

数据证据复用现有 blocked-only 审计，盘点历史股票池/身份、公司行动及分红、历史可得、来源和留出治理。自写声明不构成独立证明。提出 2026-11-09 至 2027-02-05 的未来信号日期草案，绑定候选、特征、周期、成本、停止规则及资料所有者所需记录；日期仍待所有者、日历和数据审阅。状态保持 draft/blocked，accepted_research=false、execution_authorized=false，不创建研究预约或自动采集任务，不更新共享指针。

cloc 固定官方 2.10 和 SHA256，源码不入 Git。统计 Git 跟踪的实现、测试、文档/配置/数据，排除锁文件及生成依赖。模块行数、完全重复文件、Python 入口及导入清单只用于维护参考；重复不自动抽取，外部调用入口不判定为死代码。CI 上传 JSON 和摘要，不设行数 KPI。补充模型层及纯数据/组合/评估层的导入边界测试，pytest 输出慢测试信息，不设未经测量的性能门槛。

按 TDD、完整适用检查、独立审阅和 PR 流程交付；当前组合验证通过后按长期授权合并，验证主分支/Pages，再清理本任务工作区。保留私有产物和清单。Transformer 等全量研究继续保持独立。
