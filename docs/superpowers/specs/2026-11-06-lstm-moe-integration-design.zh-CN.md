# 将 LSTM/MoE 融入 Global Market Research

状态：完整设计草案，等待审阅，尚未实施。已检查 global-market-research `b888a3a` 和 moe-lstm `14742fa`。本设计纳入用户最新要求：研究迁入 global，旧仓库和 Pages 提供迁移说明及跳转。

## 1. 要解决的问题与方案选择

让 LSTM/MoE 成为 `research/equity-lab` 中可替换的离线预测模型，共用数据校验、实验切分、账户计算和报告。研究问题是：相同数据和预算下，输入相关的专家路由是否改善预测或扣费后的模拟表现？没有改善也应完整报告。

考虑过三条路线：在 moe-lstm 重建实验平台，会重复建设；把它作为 global 的运行依赖，会带入不同的依赖与回测语义；将模型思路按现有研究边界融入 equity-lab，能复用基础设施。推荐第三条，符合用户提出的融合方向。具体设计仍待批准。

旧仓库保留 Git 历史、旧结果及来源信息。中英文 README 和 Pages 首页说明迁移，提供明确可点击链接；新 global 研究页面上线并验证后，才发布旧站跳转。旧首页可增加短暂延迟的自动跳转，但必须保留文字和手动入口；历史文档、结果链接继续可读。不删除仓库，不自动更改归档设置。

## 2. 代码归属与依赖

模型拟放在 equity-lab 的 `models/sequence/`，实验入口在 `study/sequence/`，数据适配在 `data/`，读者文档在根目录 `docs/research/`。内部文件名由实施者决定。根工具通过已安装叶子包的 CLI 和版本化产物交互，执行系统不导入研究模型。

新增可选 `neural` 依赖组，拟用 PyTorch 实现显式分发和梯度检查，实施时确定兼容版本并锁定。根项目默认安装不引入神经网络框架，不增加 TensorFlow。依据原模型数学结构重写小型模型，保留来源说明，用受控权重验证 dense 前向计算一致；不承诺两个框架训练结果相同。旧仓库未发现 LICENSE，不能默认把复制代码声明为 MIT；若要分发原代码，先确认作者授权或许可。

只复用语义匹配的既有工具。`predictive.data.prepare_daily` 依赖当前日线没有的分钟统计字段，不能直接套用。`holding_account.replay_holdings` 要求非空持仓选择且限制费率，不能直接承接全空仓模型；应基于现有现金再平衡原语新增专用研究账户，或以显式新契约扩展，保持原调用行为。禁止用演示流程的前向填充代替严格数据校验，也不把旧 CNN/排序成绩直接当作公平对照。

## 3. 数据能否使用

可以用于探索性研究。候选为外部快照 `us-fixed-daily/20261021-v2`：10 只美股和 SPY，2023-01-03 至 2026-10-20，953 个 XNYS 交易日，IBKR TRADES，美元，按拆股调整。2026-11-06 只读核验的 66 个清单文件，字节数与 SHA-256 全部匹配。这只能证明留存文件与清单一致，不能证明供应商真实性或历史当时可得。

标准化字段为 `date,open,high,low,close,volume`。入口要求明确 manifest 和预期摘要；核对 receipt、文件摘要、安全相对路径、股票覆盖、唯一有序的交易所日期、有限正数 OHLC、价格上下界及有限非负成交量。按交易所日历检查节假日、半日市和夏令时。缺少所需交易日时拒绝，不填补价格；持仓缺价不得继续产生看似完整的净值。窗口绝不跨股票拼接。

源数据只读，不复制或移动权威快照。环境、模型和输出放在 `DATA_ROOT/global-market-research/research/lstm-moe/` 的独立任务目录，不更新共享 latest/current，不改其他研究预约和验收状态。记录来源版本及全部输入摘要，结束时重新核验；输入变化使该次运行失效。私有绝对路径和精确摘要留在外部运行记录，不写入公共文档。无需连接券商或重新采集数据。

必须保留的数据限制：`fixed_current` 股票池可能存在选择及幸存者偏差；`accepted_research=false`；历史已被研究，不是全新盲测；公司行动覆盖、历史当时可得及来源证明仍不完整；价格未计分红。不能把股票数乘日期数当独立样本数。未来真正的样本外验证，需要独立冻结协议及新增未接触数据，不能重新给现有日期贴盲测标签。

拆股调整价格仅用于合成研究价格单位，不再额外调整股数或入账拆股现金，不计股息。结果明确称为拆股调整价格收益模拟，不称真实现金执行账本或总回报。原始价格加公司行动的真实账本依赖后续数据，不能重复计入调整和分红。

## 4. 标签、信号与成交时间

新主协议：交易日 t 收盘后，使用截至 t 的特征生成信号，t+1 开盘入场，t+2 开盘退出或再平衡。单日目标收益为 `open[t+2]/open[t+1]-1`；超过 0.002 标为 1，否则为 0。1 对应做多，0 对应空仓；预测概率阈值固定 0.5。禁止把 0 解释为做空，禁止看测试结果再挑阈值。

逐行保存股票、特征起止、特征可用时间、信号时间、拟合/验证截止、模型就绪时间、入场/退出日期与时间、价格、目标、概率和仓位。假设特征在交易所收盘后 15 分钟可用，并明确这只是模拟假设，不是供应商交付证据。模型必须严格早于入场就绪；历史训练按最后所需标签可用后预留 12 小时作为就绪预算，不满足则推迟到合格交易日。它不证明实际上线训练满足时限。

标签到退出时才可用。按标签区间和就绪截止清除越界样本，默认额外隔离一个交易日；不是把所有历史窗口重叠视为泄露。冻结切分再训练。

滚动使用 400 日拟合、80 日验证、63 日测试，每次推进 63 日，末段至少有 20 个合格交易日才保留。先按交易所日期划段，再应用标签与就绪过滤。缩放和筛选只拟合训练段，验证段负责早停及预先声明的选择。每折从现金开始，最后合格退出时清仓，分别报告账户；不把独立重置的多折曲线拼成连续交易净值。记录实际样本数和边缘日期排除原因。

## 5. 特征与模型对照

先用受控样例复现原 5 行、15 特征的 dense 架构，确认修正后的空仓与初始回撤语义。这是原时间协议下的兼容诊断，不与新开盘协议混比，也不覆盖旧结果。

新实验固定相对量特征：收盘收益、收盘对 MA5/MA20 的偏离、开盘对前收盘跳空、高低价差/收盘、收盘开盘差/开盘、RSI/100、MACD/收盘、20 日收益波动率、成交量/此前 20 日均量。拒绝无效分母和预热不足。主窗口 20 日，5 日和 60 日作为预先声明的后续敏感性分析。价格水平特征另作对照；KMeans、SOM、相关性筛选放在路由实验之后，只看拟合段并保存特征顺序。

首批同协议对照：现金、同期持有、固定 20 日动量规则、逻辑回归、LSTM-64、参数量匹配单 LSTM、联合训练等权三专家、三个独立 LSTM 概率平均、dense 可学习门控、真正分发的 top-2 LSTM。实际按特征数、窗口和输出头寻找最接近的单 LSTM 宽度，不固定套用 116。所有可训练配置共用样本、标签、预处理和时间切分。主面板每个候选/折/种子只训练一个跨股票共享模型；窗口仍限制在单只股票内，缩放器只汇总合格股票拟合段估计。SPY 不参与股票面板训练，仅先做独立端到端 smoke；完整 SPY 对照属于另有预算的后续实验。首版不使用股票身份嵌入，等权与独立专家集成使用同一面板训练群体。

主路由对照保留完整序列展开、最后一行门控、相同专家和输出头，只改变是否分发。按选中专家 gather 窗口，跳过空专家批次，计算后 scatter 加权表示；训练和推理均记录实际专家调用数和处理样本数。top-2 归一化保留概率；可选 top-1 保留选中 softmax 概率，不归一为恒定 1，并用非退化样例证明任务梯度非零。硬索引不可微这一近似必须说明，测试选中专家梯度及未选样本零贡献。

任务损失和均衡损失分别记录。保存原始概率、专家索引、使用比例、熵、塌陷诊断、专家表示或探针，以及固定等权、移除专家的消融。共享序列门控、共享编码器加 FFN 专家是不同的后续配置，不替换主路由比较。

LSTM 套件稳定后增加小型 dense Transformer 与 FFN-MoE Transformer：2 层、宽度 64、4 个注意力头、4 个 FFN 专家、top-2、60 日窗口。每天一个数值 token，只用历史窗口末端表示输出；完整历史窗口内可双向注意力，不暴露逐位置未来标签。分别尽量匹配总参数和激活参数预算，公开不能同时匹配的差异。无需预训练模型；以后若用预训练权重，另核验训练截止和数据重叠。

## 6. 账户、统计与运行预算

不做空、不加杠杆、不计现金利息。10 股面板初始等额分配独立资金袖套，各自按信号全仓或现金；不暗含横截面排名选股。SPY 单独评价，面板基准使用相同池和资本。每边成本取 0、5、20、40 基点，按实际成交金额计费，含首次买入及终止卖出，逐次核对现金和股数。报告毛/净收益、换手、暴露、交易次数、最大回撤及 Sharpe 假设。回撤含初始净值 1；无交易、恒定分数和未定义指标保留原因，不隐藏。未测量价差、冲击和借券不做实证声称。

固定 5 个种子：11、23、37、53、71；最多 50 epochs、patience 5、batch 32，记录确定性设置。先运行合成测试和单种子单折 SPY smoke，上限 10 分钟。真实训练前冻结候选/折/种子清单；LSTM 阶段上限 6 小时及 600 次拟合，独立三模型集成计三次。预检查发现冻结清单超过次数上限时不启动，先调整设计预算；例如 7 折、5 种子、7 类可训练候选（独立集成计三次）至多 315 次拟合。启动后超时记录 partial，不悄悄缩减对照或只保留成功者。Transformer 和后续消融各有独立 6 小时/240 次预算，主阶段未完成时保持 pending。不自动搜索参数。

记录硬件、峰值内存、同步后的拟合/推理时间、预热和重复次数、总参数、激活参数及专家处理量。没有测量不能宣称稀疏更快。

保留同日配对预测，逐折逐种子报告，与参数量匹配单 LSTM、等权 MoE 比较差值。日期区块 bootstrap 使用 20 日块、2,000 次、种子 20261106；同日股票一起抽取，不跨独立折边界。随机种子波动与时间不确定性分开报告。区间只是探索性诊断，不自动触发显著性晋级。AUC、log loss、Brier 和可靠性分箱辅助解释预测，不能替代交易风险收益。

## 7. 产物、站点与迁移

每次不可覆盖运行包保存 schema、完成/部分/待运行状态与原因、冻结配置和运行清单、来源版本、锁文件和环境、输入摘要与限制、特征顺序、缩放/筛选状态、可加载模型、种子、逐行样本及时间切分、概率、路由诊断、成交与账户标记、指标、不确定性及校验和。模型重载须在样例上复现预测。旧 CLI 和 CSV 在迁移说明指向替代入口前保持可用。

global 站点增加稳定 LSTM/MoE 研究页面，显示证据阶段、数据限制、空仓提示、模型/折/种子选择及允许下载的摘要。权益曲线按需加载本地打包的 ECharts 折线模块，支持日期提示、缩放与切换；混淆矩阵用 HTML 表格，并提供无 JS 的可访问摘要。英语默认，中文走现有词条。图表读取版本化投影契约，不接受任意私有路径。

当前行情公开发布权未核实。默认公开图表使用清楚标记的合成数据；不上传真实 OHLCV、单标的基准曲线或真实衍生时间序列。真实汇总发布须经过既有资料所有者审阅和 allowlist，并记录权利依据；不覆盖已有公开快照。测量压缩后 JS＋数据与旧 PNG 的传输体积，不承诺交互图更小，不静默降低精度。

global 页面上线并验证后，再改旧 moe-lstm 中英文 README 与 Pages，说明主维护位置、替代命令、历史版本范围及新页面链接。旧站保留可读说明和手动链接，首页自动跳转作为辅助，不破坏历史深层链接。两个仓库分别 PR，先合并提供方 global，再合并旧站迁移。

## 8. 实施阶段与验收

1. 用户批准设计，再写实施计划并审阅，之后才修改产品代码。
2. 在 global 实现可选模型、日线输入、时间契约和合成测试。
3. 完成 LSTM 公平对照、完整产物、受预算限制的探索运行；随后完成 Transformer 和其他消融，明确各配置状态。
4. 完成 global 研究页及交互合成图/获准摘要，验证部署。
5. 完成旧仓库和 Pages 的迁移说明与跳转，保留历史。

验证包括 equity-lab Ruff/pytest、根工作流边界检查和必需 CI；涉及站点时跑构建及投影检查。测试覆盖时间戳边界、缺失交易日、畸形或被篡改输入、全空仓、首末手续费、起始亏损、专家实际调用、任务梯度、参数匹配和模型重载；手算样例核对账本。页面检查两种语言、键盘访问、窄屏、无 JS 回退和网络体积。准确命令以实际项目工作流为准，不声称未执行检查通过。

使用隔离 worktree，保留无关改动，按长期授权在当前合并结果通过审阅及检查后合并，验证 main/Pages，再清理本任务分支。当前机器没有 `gh`，远端写入前按指定机器本地 GitHub 指南解决，不搜索无关凭据。不绕过依赖、CI 或数据发布限制。

软件验收要求流程可运行、审计成立、运行清单有完整状态，不要求模型一定胜出。历史成分、公司行动、当时可得、真正盲测和发布权仍是外部证据缺口，不能靠程序字段制造。内部接口、最接近的单模型宽度和可访问布局由实施者决定；改变主标签周期、股票池、账户语义或证据分类时须更新设计。
