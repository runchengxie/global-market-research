# 序列目标对照与前瞻准备设计

[English](2026-11-07-sequence-target-study-design.md)

本轮检验当前特征换用预测目标后是否含有可用信息，再决定是否扩大 MoE。用户已授权全部后续探索并取消反复确认；本文先于实施，不授权交易商访问、采集或研究认可。

固定十只股票快照、10 项相对特征、20 日窗口、下一期开盘至再下一期开盘收益、原有七折清洗边界。比较原上涨超过0.2%的分类与未来收益回归。分类标签保留，另存目标值、分数种类与原单位分数。历史已被看过。

比较拟合段先验、线性模型（分类 Logistic / 回归 Ridge alpha1）、参数量匹配的 LSTM、固定等权专家与稀疏 top2。线性模型每目标每折只拟合一次；神经模型使用11/23/37三个种子，最多30轮、早停5轮、batch128、Adam学习率.001、两线程。共140次拟合，上限180次、6小时；三个种子是有预算的筛查，不是确认。现金、持有、因果10%波动率为共同无训练对照。

回归仅用拟合段均值/标准差标准化目标，标准差下限1e-6；MSE训练后恢复收益单位。分类使用BCE。固定决策分别为概率>.5、收益>.001；另用验证段在各自五个预设阈值中选择，展示全部尝试。验证段也用于早停。费用0/5/20/40基点、首次开仓及最终平仓，长仓、无杠杆、不含股息。另加验证段冻结敞口对照，展示实际风险差，禁止按测试未来风险精确配仓。

两种目标均报告每日横截面收益秩相关；分类和回归分别使用适合自身的损失与拟合段先验比较，不将回归输出伪装为概率。配对日收益与损失改善使用20日区块、2000次抽样，先按日期平均种子，不连接折净值，不声称完成多重比较校正。

提前固定 MoE 继续条件：固定规则在5基点下对线性、单LSTM、等权的配对95%区间下限为正，20基点均值改善、对三个模型基线分别要求七折至少五折改善、相对拟合先验的预测损失改善区间下界为正（分类Brier、回归原单位MSE），以及超过验证敞口对照。逐项报告失败原因，缺数据不能通过。即使满足，也仅为回顾性值得继续，仍需独立前瞻证据才考虑更大模型。

证据包复用数据所有者的六项阻塞审计，绑定清单、回执和允许检查的来源元数据，候选资料不自动等于独立证明。不读凭证、不连接交易商。冻结2026-11-09至2027-02-05的准备协议，写明候选、目标、预算、版本和历史已暴露情况；叶子包输出未来XNYS日历及最后信号后的两个开盘，根工具仅校验文件。状态保持准备已冻结但被阻塞，不创建权威留出预约、不采集、不排程、不更新共享指针。

新命令、测试、中英文使用文档和本地结果报告一起交付；原概率浏览器不混用回归结果。真实输入和结果位于外部任务目录。公开PR可按用户授权展示汇总结果，不上传原始行情或私有路径。完成独立审阅、验证、合并和本次工作树清理，保留已有锁定的Paper工作树。

本轮改变目标、对应损失与仓位门槛，结论属于完整目标/策略方案的比较，不能单独归因于标签。前瞻准备冻结全部候选与目标，不按回顾结果挑选胜者。

## 用户追加的展示与数据粒度盘点

扩展现有中英文LSTM/MoE页面：解释20×10输入、三个64单元LSTM、最后一行特征的线性门控、1280维完整序列展平、共享标量头，以及114单元参数量对照。示意路由明确不是测量出的市场分工。展示授权公开的历史与本轮汇总结果，提供图表、筛选和无脚本表格，说明样本分母和局限；合成路径演示独立标注。延迟加载ECharts，适配主题和手机。公开投影严格拒绝原始时间序列、私有路径和逐条预测。

数字货币部分只读盘点真实保留的数据粒度、覆盖与可得时间，不把测试目录当真实数据，不将小时因子误称小时行情，不把服务能力等同本地覆盖。提出条件满足后的BTC/ETH现货4小时/1小时迁移筛查；本轮不采集、不引入衍生品或做市假设。股票目标对照继续作为可比较参照。
