# 加密货币证据、前瞻记录与公开研究

[English](2026-11-07-crypto-evidence-design.md)

公开 Pages 可以展示经过校验的真实研究汇总，附带来源、范围、不确定性和局限。原始行情、逐个预测、私有账户和配置留在外部数据目录。按已有授权直接推进，先设计再实施，不重复要求确认。

采用小型数据与线性模型实验：根工具负责公共行情采集与记录，独立 crypto 包负责研究和账本，站点只读取公开汇总。沿用执行边界，不增加 Java 服务或神经网络容量。

冻结计划后，采集 BTCUSDT/ETHUSDT 的2024年10月至2026年9月小时月度档案，48个ZIP及48个校验文件。只允许官方公共域名和准确URL，无凭据或重定向。预算112次HTTP尝试、32MiB传输、64MiB解压、每ZIP8MiB、600秒；请求前计数并保留中断状态，不盲目重试未知消耗。完整校验SHA、成员、列、OHLCV、时间单位、小时网格与月度覆盖；缺口阻塞训练，不补值。由四根完整连续小时线生成UTC四小时线。所有新输出使用专属新目录，不更新共享指针。

情绪输入通过明确路径和SHA只读消费外部数据所有者保留的 AIVIX 三指标、两资产日频快照。审查字段、重复、有限值和覆盖；不猜测指标名称，不调用私有服务。历史首次发布和修订证据仍缺失。

固定两种粒度和三个扩展时间折：拟合截至2026年3/5/7月底，分别测试随后两个月。使用七项价格/资产特征及拟合段缩放的 Ridge(alpha1)，四组为价格、价格加“周期结束24小时后可用”的未验证因子代理、再延迟48小时、再错位7天。使用共同样本交集。另列“历史时点可得已验证”组为阻塞，不把假设当证据。特征截至t，完整延迟一根K线后入场，再下一根开盘退出；清除拟合标签跨入测试决策的样本。

共24次确定性拟合，上限36次/600秒/单计算线程，不搜索参数或阈值。固定收益门槛0.002，0/10/25基点单边费用，现金/持有/因果趋势/拟合先验作对照。每资产独立等额初始资金、分数只做多或现金，计入首次开仓与最终平仓。各折从现金开始，不拼接净值。保存模型、预测和账户并重建分数；展示MSE先验改善、资产内秩相关、收益、敞口、换手、从初始净值计算的回撤及成本敏感性。相同日期配对、7日区块、2000次抽样；历史可得证据缺失时始终不晋升研究接受。

冻结新的前瞻协议并提供手动采集命令，使用真实UTC时钟，分别保存周期结束、首次收到、抓取和修订摘要。首轮旧数据只作预热/陈旧输入，不制造未来观察。只统计冻结后完成且及时记录的样本。提供本地只读监控，核对文件与状态，显示覆盖、新鲜度、完成/失败/部分状态及请求/拟合预算。使用独立安装的稳定外部环境，不启动共享调度、服务或券商。

站点增加中英文实测加密货币结果、四组对照、时间折、费用曲线、数据粒度/可得时间和前瞻状态，保留静态表格及单独标记的合成演示。公开JSON使用闭合字段契约和封存源校验；清除旧的“只展示合成”表述，检查数值与来源一致性。新前端业务模块使用严格TS和现有语言、主题、手机支持。

按英文设计中的精确预算、接口和验收要求实施；数据、实验、前瞻记录、监控与展示分别有可验证交付。设计与最终分支独立审阅，运行根包/研究包/站点测试和真实实验，待当前CI通过后合并，核验线上，再保留源码、锁文件、wheel和结果并清理本任务。真实情绪时点证据与未来表现可以明确等待，不能用人工标记制造已经完成的研究结论。
