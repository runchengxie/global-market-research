# 静态组合诊断

[English](static-allocation.md) · [README](../README.zh-CN.md)

先比较分散配置与调仓，再增加预测模型。独立模块复用 `portfolio.cash_rebalance`，不使用原有的每日目标权重引擎，也不导入券商或根项目代码。

在子包锁定的 Python 3.12 环境运行：

```sh
python -m equity_lab.backtest.static_allocation --input panel.json --protocol protocol.json --output new-result.json
```

输入为严格按 ISO 日期递增的 JSON 数组，每行恰好包含 `date`、`open`、`close`；两种价格对象必须始终包含相同的非空标的集合，价格须为有限正数。`_cash` 为保留名称。单行示例：

```json
{"date":"2024-01-02","open":{"A":100,"B":80},"close":{"A":101,"B":79}}
```

运行前，调用方必须核对完整交易日历与来源。回放不会补齐价格，也不会推断缺失交易日。使用含分配调整的价格单位时，开盘与收盘须使用同一天相同的调整因子，不再另加股息现金。

协议须给出实际首末日期、完整政策与费用矩阵，以及合计不超过一的多头目标权重：

```json
{
  "schema":"equity.static_allocation_protocol.v1",
  "start":"2024-01-02","end":"2024-12-31",
  "currency":"USD","cash_yield":0,"threshold":0.05,
  "fees_bps":[0,10,25],"policies":["hold","monthly","drift"],
  "targets":{"stock_cash":{"A":0.5},"diversified":{"A":0.5,"B":0.25}}
}
```

剩余权重为现金。首日开盘建仓；月度政策在输入中每月第一个交易日开盘调仓；偏差政策根据前一收盘的权重（含现金）决定，在下一输入交易日开盘执行。阈值为权重绝对差，`0.05` 表示5个百分点。费用按成交金额收取，从组合财富中支付。分数单位在两次交易间自然漂移。最后一个收盘全部退出，并计退出费用。

不可覆盖的输出保存输入与协议 SHA256、全部配置、每日净值、交易、实际开盘敞口及连续路径的年度收益。年度切片不是独立重新建仓，首末年可能不足一年。回撤包括初始资金、交易后开盘、收盘及退出费用，不包含日内极值；每日收盘收益波动按252日年化。`traded_initial_capital` 为成交金额除以初始资金（一），不是比赛官方换手率。最后一个每日净值已扣退出费用，但该行权重与现金描述退出前持仓；`terminal_cash` 为退出后的最终现金。交易记录中的数量为交易后数量。

相同股票目标权重不保证相同实际平均股票敞口或总风险。零利息美元现金不等于新元账户现金。调整价格单位不模拟可成交股数、实际到账分配、手数、税费、汇率、预扣税或独立核验的公司行动。来源与时点验收另行处理。任何配置都不会自动成为策略或订单。
